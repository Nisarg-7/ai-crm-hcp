# LangGraph Agent Tools (proposed, finalized in Week 2)

| Tool | Purpose |
|---|---|
| log_interaction | Extract structured interaction data from natural language and save it |
| edit_interaction | Modify fields of an existing logged interaction |
| search_hcp | Find an HCP by name, specialty or city |
| get_interaction_history | Return recent interactions for an HCP |
| schedule_followup | Create a follow-up action with due date for an interaction |
| suggest_next_action (optional) | Suggest next steps from interaction history |
